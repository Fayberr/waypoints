# Modern Waypoints Mod Specification & Architecture

## Overview
**Modern Waypoints** is a client-side Fabric mod for Minecraft 26.1.x and 26.2 that provides clean, modern waypoints inspired by Feather/Lunar Client without requiring heavy map suites.

---

## 1. Core Requirements

1. **Client-Side Only**:
   * `"environment": "client"` in `fabric.mod.json`.
   * Completely safe and functional on vanilla servers, Hypixel, modded servers, and singleplayer.
2. **Multi-World & Multi-Server Scoping**:
   * Isolated storage per singleplayer world folder, multiplayer server address, and Realm.
   * Waypoints created on Server A never leak into Server B or Singleplayer worlds.
   * Dimension-aware filtering (Overworld, Nether, The End, and custom dimensions).
3. **Modern Visuals**:
   * **Modern Floating Pins**: Crisp geometric markers / billboard pins in-world with dynamic scale compensation.
   * **Modern Vertical Beam**: Smooth, translucent vertical glowing cylinder / quad beam with configurable opacity and top/bottom fading.
   * **Dynamic Distance Tags**: Real-time distance calculation (e.g., `[142m]`) scaling gracefully with camera distance.
   * **Chroma / Rainbow Mode**: Dynamic HSV color cycling for beams and pins.
   * **Screen-Edge Clamping Pointers**: Off-screen HUD indicators pointing towards waypoints outside the camera FOV.
4. **Death Waypoints**:
   * Automatic capture upon player death (`Death - HH:mm`).
   * Configurable auto-removal on pickup/approach (within N blocks).
   * Configurable history retention (keep latest only vs. keep all).
5. **Modern In-Game GUI**:
   * Clean dark/frosted-glass user interface.
   * Search and filter by name, dimension, or distance.
   * Quick toggle visibility, edit, delete, and teleport buttons.
   * Color picker with preset swatches, hex input, and chroma mode.
6. **ModMenu & Cloth Config Integration**:
   * Full ModMenu entrypoint.
   * Cloth Config GUI with categories (General, Visuals, Death Waypoints, Keybindings).

## 3. Data Models

### `Waypoint.java`
```java
public class Waypoint {
    private UUID id;
    private String name;
    private double x, y, z;
    private String dimension;       // e.g. "minecraft:overworld"
    private int color;              // ARGB integer (0xAARRGGBB)
    private boolean chroma;         // Dynamic animated rainbow effect
    private boolean visible;        // In-world visibility toggle
    private boolean showBeam;       // Vertical beam toggle
    private boolean showLabel;      // Name tag toggle
    private boolean showDistance;   // Distance tag toggle
    private String icon;            // "pin", "skull", "star", etc.
    private long createdAt;         // Epoch timestamp
    private boolean deathWaypoint;  // True if generated by death system
}
```

### `ModConfig.java`
```java
public class ModConfig {
    public int renderDistance = 10000;               // Max render distance in blocks (0 = infinite)
    public float beaconWidth = 0.20f;                // Beam thickness in blocks
    public float beaconAlpha = 0.65f;                // Beam opacity (0.0 - 1.0)
    public float beaconHeight = 384.0f;              // Vertical beam height
    public float pinScale = 1.0f;                    // In-world pin scale factor
    public float textScale = 1.0f;                   // Label font scale factor
    public boolean alwaysOnTop = true;               // Render through walls (disable depth test)
    public boolean showOffscreenPointers = true;     // Screen-edge clamp arrows
    public boolean deathWaypointEnabled = true;      // Auto-create waypoint on death
    public boolean deathWaypointAutoRemove = true;   // Remove death waypoint on approach
    public double deathWaypointAutoRemoveDist = 6.0; // Distance in blocks for auto-removal
    public int deathWaypointMaxCount = 1;            // Number of death waypoints to keep (1 = latest)
}
```

## 4. World Scoping & Persistence

### Storage Path
All world waypoints are stored under:
`<game_dir>/config/waypoints/worlds/<sanitized_world_id>.json`

### `WorldIdResolver` Logic:
1. **Singleplayer**:
   `sp_` + sanitized world folder name (from `Minecraft.getInstance().getSingleplayerServer().getWorldData().getLevelName()`).
2. **Multiplayer Server**:
   `mp_` + sanitized server IP (from `Minecraft.getInstance().getCurrentServer().ip`, with port normalized).
3. **Realms**:
   `realm_` + realm ID or name.
4. **Fallback / Offline**:
   `local_default`.

## 5. Rendering Pipeline Details

### In-World 3D (WorldRenderEvents.AFTER_TRANSLUCENT)
* **Coordinate Transformation**:
  All rendering is done relative to the camera position (`camera.getPosition()`).
  Translate matrix by `(waypoint.x - camX, waypoint.y - camY, waypoint.z - camZ)`.
* **Beam Rendering**:
  * Render a vertical polygonal cylinder or cross-quads from `y - 128` to `y + beaconHeight`.
  * Calculate vertex alpha with smooth top/bottom falloff.
  * Use custom translucent render type or `RenderType.translucent()`.
* **Billboard Pin & Text**:
  * Apply camera rotation to matrix: `matrixStack.mulPose(camera.rotation())`.
  * Compute distance scaling: `scale = Math.clamp(distance * 0.0025f, 0.5f, 5.0f) * pinScale`.
  * Draw diamond/pin shape with outline and colored fill.
  * Draw text using `Font.drawInBatch` with a dark drop-shadow / background box.
* **Always-On-Top Mode**:
  * When `alwaysOnTop == true`, disable OpenGL depth test during render (`RenderSystem.disableDepthTest()`) and re-enable afterwards.
